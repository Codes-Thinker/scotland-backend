# Backend

No backend is available in this workspace yet.

The **mobile app** and **admin dashboard** currently use **local mock data** so UI and role flows can be developed without a live API.

When a backend is ready:

1. Place the existing API project in this folder (or link the remote repo).
2. Point `mobile_app` and `admin_dashboard` at the same API base URL.
3. Replace mock repositories with real HTTP clients — do not duplicate business logic in the frontends.

Until then, treat this folder as a reserved slot for the existing backend.
